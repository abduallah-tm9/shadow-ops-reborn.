# Shadow Ops: Reborn — نسخة متصفح تجريبية

لعبة تصويب تجريبية مستوحاة من ألعاب التصويب والزومبي، وليست نسخة من Call of Duty.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub باسم `shadow-ops-reborn`.
2. ارفع الملفات `index.html` و`manifest.json` و`sw.js` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر نشر الموقع، ثم افتح الرابط الذي يعرضه GitHub Pages على هاتف Android.

## التحكم
- لمس الهاتف: عصا الحركة أسفل اليسار، اسحب على مساحة اللعب للنظر، وأزرار إطلاق/تلقيم/تفاعل.
- لوحة المفاتيح: WASD أو الأسهم، الفأرة للتصويب، النقر للإطلاق، `E` للتفاعل، `R` للتلقيم، `1–6` لاختيار السلاح.
- يد PS5: وصّل DualSense عبر Bluetooth، وافتح اللعبة في متصفح يدعم Gamepad API. قد يختلف الدعم حسب المتصفح وإصدار Android. جرّب العصا اليسرى للحركة، اليمنى للنظر، R2 للإطلاق، X للتفاعل، □ للتلقيم و△ لتغيير السلاح.

## ما تتضمنه هذه النسخة
- ساحة تصويب بمنظور أول مبسّط.
- موجات زومبي ونقاط وفتح بوابة.
- قائمة تجريبية من 60 سلاحًا وواجهة لتعديل الملحقات.
- حفظ ملفات الموقع للاستخدام دون اتصال بعد تحميل الموقع مرة واحدة وتفعيل Service Worker في متصفح يدعمه.

## ملاحظات
هذه نسخة أولية: لا تتضمن بعد رسومًا ثلاثية الأبعاد كاملة، أو ذكاء اصطناعي متقدمًا، أو حفظ تقدم دائمًا، أو ضمانًا لدعم كل أزرار DualSense على كل جهاز. يلزم فتح الموقع عبر HTTPS (مثل GitHub Pages) لتفعيل Service Worker.
